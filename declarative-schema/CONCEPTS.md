# Declarative schema CLI concept panel

This is the planned set of independent migration fixtures for exercising the
pg-delta next round trip through the Supabase CLI. A checked item has a matching
SQL file under `migrations/`; an unchecked item is planned but not implemented.

Each fixture starts from its migration, generates declarative schema, removes
the migration from the isolated working copy, and asks the CLI to regenerate a
migration from that declarative schema.
